# HTML5 e CSS3 — Curso em Vídeo

Este diretório reúne os exercícios, desafios e projetos desenvolvidos durante o curso **HTML5 e CSS3** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O curso é composto por cinco módulos e aborda desde os fundamentos do HTML até conceitos avançados de CSS, incluindo responsividade, Flexbox e Grid Layout.

## Objetivo

Documentar meu aprendizado ao longo do curso por meio da resolução dos exercícios, desafios e projetos propostos, registrando minha evolução na construção de páginas web utilizando HTML5 e CSS3.

## Tecnologias praticadas

- HTML5
- CSS3
- HTML Semântico
- Box Model
- Flexbox
- CSS Grid
- Responsividade
- Media Queries
- Mobile First
- Variáveis CSS
- Pseudo-classes
- Pseudo-elementos
- Formulários
- Tabelas
- Iframes

## Conteúdo

### Módulo 01 — Introdução ao HTML

Principais tópicos:

- Estrutura básica de documentos HTML
- Títulos e parágrafos
- Listas
- Links
- Imagens
- Áudio e vídeo
- Semântica básica

### Módulo 02 — Introdução ao CSS

Principais tópicos:

- CSS Inline, Interno e Externo
- Seletores
- Classes e IDs
- Fontes
- Cores
- Box Model
- Unidades de medida

### Módulo 03 — HTML e CSS Avançado

Principais tópicos:

- Tabelas
- Formulários
- Pseudo-classes
- Pseudo-elementos
- Posicionamento
- Transições
- Organização do código

### Módulo 04 — Responsividade e Iframes

Principais tópicos:

- Media Queries
- Mobile First
- Menus Responsivos
- Iframes
- Adaptação para diferentes dispositivos

### Módulo 05 — Flexbox e Grid Layout

Principais tópicos:

- Flexbox
- Grid Layout
- Layouts Responsivos
- Alinhamento e Distribuição de Elementos
- Interfaces Modernas
