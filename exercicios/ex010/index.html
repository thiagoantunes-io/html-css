Trabalhando com links

Usando links externos

Link Externo
É um link que vai apontar para outro site que não é nosso.

Ex.:
Você pode acessar o meu repositório público no GitHub.

Você também pode acessar o meu canal gratuito no YouTube.

Usando links internos

Link interno
É um link que vai fazer a relação com outra página que está dentro do nosso servidor que diz respeito a nossa própria página. Então, para criar link interno precisams que o nosso site tenha outras páginas

Ex.:
Esta é a a primeira páginado site. Se você quiser, pode acessar também a minha segunda página

Você também pode acessar a nossa página de notícias
