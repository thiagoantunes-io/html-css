# HTML e CSS

Repositório dedicado aos meus estudos de **HTML5** e **CSS3**.

Aqui concentro exercícios, desafios, projetos e anotações desenvolvidos durante cursos e estudos independentes, organizados por plataforma de ensino. O objetivo é documentar minha evolução, consolidar conhecimentos e manter um histórico organizado do aprendizado em desenvolvimento front-end.

## Objetivo

Este repositório serve como um registro da minha jornada de aprendizado em HTML e CSS, reunindo conteúdos produzidos ao longo dos estudos e demonstrando a evolução das minhas habilidades na construção de interfaces web.
